# 编辑器包

共享的受控 HTML 文档模型、TipTap 扩展、序列化/反序列化、模板占位符、结构化 Diff 节点和内容操作协议。

该包只定义编辑领域能力，不包含页面、鉴权、业务 API 调用或租户状态。文档模型发生不兼容变化时必须提供迁移器并记录技术版本。

当前已提供 `ControlledDocument` v1 模型，覆盖段落、标题、列表、表格、图片、页眉页脚、目录、分页标记以及 Schema 字段占位符和数组重复块。所有节点使用稳定 ID；占位符只接受纯文本、清洗后的富文本或受控资源引用，不支持表达式和任意 HTML。

安全 HTML 由受控模型确定性生成，并在惰性 `<template>` 中保存转义后的版本化模型元数据。反序列化只接受匹配白名单版本和固定 CSS 的 DocMind 文档，不把外部任意 HTML 猜测为内部模型。粘贴内容可先调用白名单清洗接口；脚本、事件处理器、外链资源和不安全 CSS 会被移除。
