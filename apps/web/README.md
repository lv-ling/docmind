# Web 应用

Vue 3 + TypeScript + Vite 用户端。负责原件只读预览、字段 Schema 配置、抽取结果复核、模板编辑、模板实例填写、编辑锁状态和文档对比。

建议内部结构：`src/api` 契约客户端、`src/features` 业务模块、`src/views` 页面、`src/router` 路由、`src/stores` 状态、`src/components` 应用组件。通用编辑能力放到 `packages/editor`，通用组件放到 `packages/ui`。

禁止在浏览器保存模型密钥、敏感令牌映射或绕过 API 直接访问对象存储私有对象。

当前 v0.1 已实现上传与原件版本、Schema/敏感规则配置、抽取任务与人工复核、模板转换与双栏校验。模板工作台左侧通过 Bearer 鉴权获取短生命周期 Blob URL 展示不可变 PDF，右侧仅编辑 `@docmind/editor` 受控模型；支持分栏拉伸/收起、预览/微调切换、文字/字号/对齐/页边距调整、转换告警定位、后端版本 Diff、发布和生成新版本式回滚。分栏偏好按用户与工作区保存在本地，模型内容和对象存储地址不写入本地存储；会话失效时清除令牌并安全返回登录页，登录后只允许恢复工作区内路径。
