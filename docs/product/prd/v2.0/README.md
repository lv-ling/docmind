# PRD v2.0

状态：Draft  
定位：DocMind 全功能产品需求基线。

本版本统一此前分散在 v0.1、v0.1.1、v0.2、v1.0 和 `custom_prd.md` 中的需求，覆盖身份认证、工作台、文档资产、安全抽取、人工复核、原生模板编辑、字段绑定、文档生成、内部待办、外部链接填写、三种来源组合的文档对比、对比并调整、智能审阅、权限、版本和审计。

已确认的业务文档基线：业务文档只能从已发布 `fillable` 模板手动创建，内部编辑与外部链接互斥；业务文档始终只有一份当前内容且不展示版本号，提交与审批等关键节点仅生成内部只读审计快照；审批人只读并支持顺序多级审批。

详细需求见 [PRD.md](PRD.md)。

技术选型、关键文档能力方案、实施顺序和逐页任务见 [implementation/README.md](implementation/README.md)。
