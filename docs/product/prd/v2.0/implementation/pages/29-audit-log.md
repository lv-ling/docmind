# P29 审计日志

## 页面定义

- 路由：`/settings/audit`，对应原型 `#audit`。
- 访问：管理员查询全工作区；普通用户在业务对象详情只看有权限时间线。
- 目标：检索追加写入的安全审计记录并导出权限过滤结果。

## 布局

- 页头：标题、保留策略摘要、导出。
- 筛选：时间范围、操作者、动作、对象类型、对象 ID、结果、request ID。
- 表格：时间、操作者、动作、对象类型/ID、结果、客户端来源摘要、request ID、详情。
- 详情 Drawer：前后状态、失败码、关联任务/快照摘要；不显示正文或敏感字段。

## 规则

- 默认最近 24 小时，服务端分页；长时间范围导出走异步任务。
- 审计记录不可由普通用户编辑或删除。
- 导出继续执行对象权限和字段掩码；文件短期下载并审计“审计导出”。
- 禁止记录正文、完整敏感字段、对象存储地址、签名 URL、模型密钥、内部 Prompt。
- IP 是否显示按工作区安全权限；普通业务时间线不显示无必要 IP。

## 实现拆分

- `AuditFilterBar`、`AuditTable`、`AuditEventDrawer`、`AuditExportDialog`。
- action/object/result 使用服务端枚举与本地文案映射，不直接显示内部类名。
- request ID 可复制，用于运维关联；复制按钮有可访问名称。

## 验收

- 组合筛选、分页和导出结果一致。
- 导出大范围不会阻塞请求，完成后发通知。
- 安全扫描确认日志/响应/CSV 无禁止字段。
- 越权对象的审计不会出现在查询总数中。
