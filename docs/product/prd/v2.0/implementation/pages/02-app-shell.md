# P02 全局应用壳与通知

## 页面定义

- 适用：除登录、外部填写和系统错误页外的全部内部路由。
- 目标：提供统一导航、工作区上下文、全局搜索、通知和会话退出。

## 布局

- 左侧可折叠导航：品牌/工作区、一级导航组、当前用户与退出。
- 顶栏：面包屑、全局搜索、工作区选择器、通知、帮助与用户菜单。
- 主内容区：路由页面、全局加载条、Toast、Dialog 与 Drawer portal。
- 侧栏折叠偏好可以保存到按 `user_id + workspace_id` 隔离的无敏感 localStorage key。

## 导航与权限

- 导航：工作台、文档资产、抽取任务、复核队列、抽取方案、模板中心、业务文档、我的待办、外部提交、文档对比、智能审阅、数据安全、成员、模型、审计。
- 导航显示按 capability 控制；隐藏入口不能替代服务端权限校验。
- 不再提供原型中的“演示角色切换”生产入口。
- 工作区切换必须重新加载角色、能力、未读数与当前页面权限；无权限时进入工作台并提示。

## 全局搜索

- 输入 2 个字符后防抖请求；按原件、模板、业务文档、任务分组。
- 结果只包含当前工作区和当前用户可见对象。
- 选择结果时使用稳定对象路由；失效结果显示“资源不可访问”。

## 通知抽屉

字段：标题、事件类型、对象名称、相对/绝对时间、已读状态、目标对象。

- 打开抽屉加载分页通知；点击后先标记已读，再跳转目标。
- 提供“全部标记已读”；无权限通知不显示历史敏感摘要。
- 新待办、转交、驳回、传阅、外部提交、任务失败和批注回复产生通知。
- SSE 推送仅传通知 ID/类型等最小信息，详情再鉴权读取。

## 实现拆分

- 复用 `layouts/AppShell.vue`、`WorkspaceSidebar.vue`、`GlobalHeader.vue`。
- 新增 `NotificationDrawer`、`GlobalSearchCombobox`、`WorkspaceSwitcher`。
- Pinia 只保存跨路由身份、工作区和未读数量；抽屉分页留在 composable。
- 所有 overlay 基于 `DmDialog/DmDrawer/DmCombobox`，统一焦点恢复。

## 验收

- 键盘可完成展开导航、搜索、打开通知和退出。
- 工作区切换不会短暂显示前一工作区敏感数据。
- 通知目标权限失效时不会泄露原摘要。
- 侧栏折叠、主内容滚动和窄屏 Drawer 布局可用。

## 子任务

- P02-T1：定义导航 capability 和工作区切换流程。
- P02-T2：实现全局搜索与通知 API/组件。
- P02-T3：补焦点、键盘、跨工作区缓存和权限回归测试。
