# P16 业务文档详情与时间线

## 页面定义

- 路由：`/business-documents/:id`，对应原型 `#bizdoc-detail`。
- 目标：查看当前内容、来源、责任人、完整流程时间线和内部审计快照证据。

## 布局

- 顶部摘要：名称、状态、模式、模板版本、发起人、当前处理人、审批进度。
- 操作栏：按状态显示填写、审批、仅对比、对比并调整、智能审阅、下载、取消/删除。
- Tab：当前内容、流程时间线、字段摘要、批注、相关任务。
- 快照详情使用只读 Drawer/Dialog，不把快照作为普通版本列表或恢复入口。

## 时间线字段

动作类型、操作者/外部会话标识、时间、处理意见、前后状态、审批级次、快照摘要、request ID、相关待办/外链轮次。敏感字段与正文不直接写在事件摘要中。

## 快照规则

- 提交、驳回、批准、抽取、对比、智能审阅产生内部只读快照。
- 页面以“提交内容（时间）”“驳回时内容”等业务语义展示，不显示业务版本号。
- 快照不可编辑、恢复或作为新业务入口；只用于证明、审批和重放。

## 操作规则

- 仅当前内部编辑人显示“对比并调整”和可写审阅。
- 审批、外部、完成状态只有只读对比/审阅。
- 取消活动流程先关闭待办；删除外部文档先撤销外链；完成文档进入回收站。
- 下载当前 DOCX/PDF 要显示名称、导出时间、流程状态，不展示版本号。

## 实现拆分

- `BusinessDocumentSummary`、`WorkflowTimeline`、`SnapshotViewer`、`RelatedTaskList`。
- 时间线服务端分页；当前内容与时间线局部独立加载。
- 操作能力由服务端 `allowed_actions` 或统一 capability mapper 决定。

## 验收

- 审批人看到的是提交快照和当前状态，不能修改字段。
- 快照没有编辑/恢复入口，且固定摘要可验证。
- 删除、取消、撤链顺序符合状态机并写审计。
- 权限撤销后时间线不泄露历史敏感摘要。

## 子任务

- P16-T1：定义时间线/快照/相关任务聚合 API。
- P16-T2：实现详情 Tabs、快照查看和动作栏。
- P16-T3：补状态动作、导出、取消/删除 E2E。
