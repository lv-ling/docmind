# P25 智能审阅与 AI 文档助手

## 页面定义

- 路由：`/reviews/:id`，对应原型 `#review-detail`。
- 目标：基于固定快照查看默认审阅、证据和 AI 对话；合法编辑人确认后应用建议。

## 布局

- 顶栏：文档名、输入版本/快照时间、状态、可编辑性、重新审阅、审阅完成。
- 左侧约 60%：只读 PDF/文档视图；可编辑业务仅在合法会话显示受控修订能力。
- 右侧约 40%：`DmAiConversation`，默认审阅建议、对话、表格/图表消息和输入框。
- 建议筛选 Drawer：类别、严重程度、状态、是否可应用。

## 默认审阅建议

字段：类别、严重程度、问题说明、原文位置、证据、建议替换、输入快照、状态、处理人/备注。

类别覆盖错别字、语法/标点、术语/表达一致性、编号/日期/金额/引用一致性、缺失/重复/矛盾。无法定位的建议只能显示一般提示，没有“一键应用”。

## AI 对话

- 支持总结、提取、分类、统计、文档内问答、表格和柱/线/饼图。
- 消息使用结构化 block：text、markdown_table、chart、suggestion、evidence；禁止执行模型 HTML/JS。
- 表格/图表标注数据来源和证据，可导出；插入业务文档需要当前编辑人确认。
- 每个回答绑定 review snapshot；不知道或文档无信息时明确说明。

## 建议处理

- 只读输入：复制建议、忽略/备注，不能应用或创建业务文档。
- 可编辑业务：接受前展示 before/after；批量应用展示变更清单并确认。
- 应用进入草稿，保存时更新同一业务文档并生成审计；旧建议标 outdated。
- 内容变化后重新运行会创建新审阅快照，不覆盖历史任务。

## 证据定位与安全

- 点击证据调用 `DocumentEvidenceAnchor` 定位左侧；重定位失败标“需重新定位”。
- 全链路复用 PII 令牌化和输出二次扫描；对话历史按工作区+快照隔离。
- 模型供应商不得默认使用数据训练；日志不记录文档、对话正文或内部 Prompt。
- 所有 AI 输出标为建议，不替代法律/财务/合规判断。

## 实现拆分

- `ReviewDocumentPane`、`DmAiConversation`、`AiSuggestionCard`、`AiEvidenceLink`、`AiChartBlock`。
- 消息 renderer 用 Vue 组件白名单，不用未经净化的 `v-html`。
- 编辑写回复用业务文档保存/租约 composable；对话流可用 SSE。

## 验收

- 进入详情自动创建/恢复默认审阅，不重复创建任务。
- 无明文权限时模型请求、响应、日志和 UI 通过零泄露检查。
- 只读对象不存在应用/保存入口；合法编辑人每次写入都人工确认。
- 内容保存后旧建议清楚标记过期。

## 子任务

- P25-T1：完成 G4 输出协议、PII 和证据安全评测。
- P25-T2：实现结构化 AI 消息、建议/证据/图表组件。
- P25-T3：实现建议预览、批量确认、保存和过期。
- P25-T4：补 prompt injection、恶意 Markdown、越权和证据重定位测试。
