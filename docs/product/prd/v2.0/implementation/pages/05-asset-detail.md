# P05 原件详情与安全预览

## 页面定义

- 路由：`/sources/:sourceId`，对应原型 `#asset-detail?id=...`。
- 目标：查看逻辑文档及不可变版本，安全预览并从指定 ready 版本发起派生任务。

## 布局

- 顶部：返回、文档名、格式/状态、完整摘要、上传人；右侧派生操作。
- 主区左侧：`DmPdfViewer` 只读预览。
- 主区右侧：版本列表、当前选中版本元数据、衍生历史和任务进度。
- 模板转换使用 Dialog；失败任务详情使用 Drawer。

## 版本字段

版本号、原始文件名、格式、大小、SHA-256、上传人、上传时间、验证状态、预览状态、页数、失败阶段、是否当前版本。

切换版本后预览、摘要和所有派生入口都必须绑定该版本 ID，不能只使用逻辑文档 ID。

## PDF 预览

- 使用 `DmPdfViewer`：翻页、页码、缩放、适宽、搜索、下载。
- 预览内容从 `/source-previews/{id}/content` 同源鉴权读取。
- loading、preview_failed、无权限、加密 PDF、空文档分别显示明确状态。
- 页面水印只能作为威慑，不能替代对象权限和下载控制。

## 派生操作

- ready：智能抽取、转换模板、仅对比、智能审阅、下载。
- 非 ready：禁用派生并显示阻断原因；可重试的预览失败显示重试。
- 转换模板字段：模板名称、用途说明、类型 `fillable/reference`、可选已发布抽取方案版本。
- 已成功转换过时优先显示“查看模板/复制为新模板”，不重复创建同一转换。

## 衍生历史

显示抽取、模板转换、对比、智能审阅任务的状态、创建人、创建时间和目标链接；原件本身状态不混入这些任务进度。

## 实现拆分

- 延续 `views/source/detail`；抽出 `SourceVersionList`、`SourceDerivedTaskPanel`、`DmPdfViewer`。
- 版本选择保留在路由 query，刷新可恢复。
- 预览二进制使用可取消请求；卸载时清理 loading task 和 canvas。

## 验收

- 切换版本不会误对另一版本发起任务。
- 原件任何状态都没有正文编辑入口。
- 预览失败时仍可按权限下载已验证原件并单独重试预览。
- 模板转换重复请求符合幂等与“复制新模板”规则。
