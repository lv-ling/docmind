# P09 新建抽取任务

## 页面定义

- 路由：`/extractions/new`，对应原型 `#extraction-wizard`。
- 目标：固定输入、抽取方案、安全策略与运行版本，创建可审计异步任务。

## 布局

- 居中向导：输入来源、抽取方案、安全策略、确认摘要。
- 可从原件详情预填 source version，也可从业务文档详情预填 business document。
- 新上传文件复用资产上传 Dialog；验证完成前不能进入下一步。

## 字段

| 步骤 | 字段 | 规则 |
| --- | --- | --- |
| 1 | 输入来源 | ready 原件版本、当前业务文档、上传新文件，三选一 |
| 2 | 抽取方案版本 | 必须是已发布或历史已发布且允许使用的版本 |
| 3 | 敏感规则版本 | 可选；默认工作区当前已发布版本 |
| 4 | 任务名称/备注 | 名称可默认生成；备注不得进入模型 Prompt |

确认页显示输入摘要、对象类型、原件/快照时间、方案版本、策略版本、模型/解析器配置摘要和隐私说明。

## 业务规则

- 业务文档创建任务时先生成内部抽取快照，后续编辑不改变该任务输入。
- 模板不是默认抽取入口；原件和上传文件不会被转换成业务文档。
- 创建请求带幂等键；成功响应返回 extraction ID、job ID、request ID。
- 敏感规则服务不可用时任务失败或进入安全复核，不能允许用户跳过。

## 实现拆分

- `DocumentPicker` 统一选择原件版本/业务文档/上传。
- `ExtractionCreateSummary` 渲染固定输入，不在页面拼接 Prompt。
- 创建后跳任务详情/列表，并通过 SSE 恢复进度。

## 验收

- 非 ready 原件、无已发布方案、无对象权限均无法创建。
- 同一幂等键重放返回同一任务。
- 业务文档创建任务后继续编辑，任务输入摘要保持不变。
- 取消向导不会残留未清理的临时上传会话。

## 子任务

- P09-T1：扩展抽取输入联合类型与业务快照 API。
- P09-T2：实现 DocumentPicker 和确认页。
- P09-T3：补三种输入、幂等和快照固定测试。
