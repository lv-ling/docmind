# P30 无权限、404 与全局异常页

## 页面定义

- 路由：`/forbidden`、`/:pathMatch(.*)*`，对应原型 `#no-permission` 和 404。
- 另含：会话失效、资源不存在/已删除、服务暂不可用、离线与维护状态。

## 布局

- 简洁状态图标、标题、用户可理解说明、request ID（适用时）、主要/次要动作。
- 登录失效使用独立跳转；业务异常尽量保留应用壳和安全上下文。
- 不显示堆栈、内部 URL、对象键、SQL、模型响应或原始异常。

## 状态与动作

| 状态 | 主要动作 |
| --- | --- |
| 401 会话失效 | 安全退出并去登录，保存允许的内部回跳路径 |
| 403 无权限 | 返回工作台/上一安全页面；不提供原型“一键切 Owner” |
| 404 不存在 | 返回所属列表或工作台 |
| 410 已删除/过期 | 查看回收站或业务终态说明（按权限） |
| 409 冲突 | 刷新最新内容、复制本地修改、进入对比 |
| 5xx/依赖故障 | 重试、返回列表、复制 request ID |
| 离线 | 显示未保存风险，恢复网络后手动重试 |

## 全局错误处理

- API client 将错误契约映射为领域错误，不按字符串判断。
- 页面级加载错误使用 `DmErrorState`，短暂动作失败使用内联提示/Toast。
- 危险操作失败必须说明数据是否已改变，不能只显示“操作失败”。
- Error boundary/全局 Vue handler 只上报脱敏元数据。

## 验收

- 403 与 404 响应不泄露对象是否真实存在。
- 浏览器后退不会重新显示已退出的敏感页面缓存。
- 每个可重试错误有明确下一步且不会重复业务副作用。
- 生产页面没有演示角色提升或调试堆栈入口。

## 子任务

- P30-T2：实现系统页与页面级 ErrorState。
- P30-T3：补 401/403/404/409/5xx/离线导航和缓存测试。
