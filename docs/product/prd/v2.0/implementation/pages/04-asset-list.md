# P04 文档资产列表与上传

## 页面定义

- 路由：`/sources`，对应原型 `#assets`。
- 目标：检索不可变逻辑文档，上传新文档或向指定逻辑文档添加版本。

## 布局

- 页头：标题、不可变说明、上传按钮。
- 筛选栏：关键词、格式、状态、上传人、上传时间、排序和重置。
- 数据表：文档名称、最新版本、格式/大小、摘要短值、状态、上传人、时间、操作。
- 上传 Dialog：选择“新逻辑文档/添加到已有文档”，文件区与分阶段进度。

## 列表字段与筛选

- 关键词搜索文件名；摘要搜索需要精确或足够长前缀，避免昂贵模糊查询。
- 格式：DOC、DOCX、PDF；状态：uploading、verifying、previewing、ready、validation_failed、preview_failed。
- 服务端分页，默认每页 20；排序支持上传时间、文件名、大小。
- 无对象权限的文档不能出现在总数、筛选项或搜索结果中。

## 上传字段

| 字段 | 规则 |
| --- | --- |
| 归属模式 | 新逻辑文档或明确选择已有逻辑文档 |
| 文件 | 单文件；`.doc/.docx/.pdf`；最大 10MB |
| 文档名称 | 新逻辑文档必填；默认取安全文件名，可修改 |
| 备注 | 可选，不含敏感正文 |

## 上传流程

1. 浏览器校验扩展名/大小并用 Web Crypto 计算 SHA-256。
2. 创建带幂等键的上传会话，取得 staging 上传参数。
3. 直传 MinIO staging；UI 显示 hashing/uploading，不声称已安全验证。
4. 调用 complete；服务端重新验证真实 MIME、大小、摘要、ETag 和恶意结构。
5. 状态进入 verifying/previewing；通过 SSE 或轮询更新。
6. 预览失败不删除已验证原件，提供“重试预览”和“下载原件”。

## 行操作

- 详情、下载、重试预览、添加新版本、进入回收站申请。
- 抽取/模板/对比/审阅派生操作放在详情页，列表仅保留快捷菜单。
- 被历史任务引用的原件不得直接物理删除。

## 实现拆分

- 延续 `views/source/list`，复用现有上传 composable。
- 列表升级为 `DmDataTable`；Dialog 使用 `SourceUploadDialog`。
- 文件散列放 Web Worker，避免 10MB 文件阻塞 UI。
- Object URL、Worker、SSE 在取消/卸载时清理。

## 验收

- 相同文件重复提交不会产生重复业务对象；同一幂等键不同请求返回冲突。
- DOCX 伪装、ZIP 炸弹、宏/OLE/外链等失败显示安全错误且不泄露内部诊断。
- 用户刷新后可以恢复上传后续状态。
- 新版本必须由用户明确选择目标逻辑文档。

- P04-T2：实现散列 Worker、上传恢复与分阶段进度。
