# P01 登录

## 页面定义

- 路由：`/login`，对应原型 `#login`。
- 访问者：未登录用户；已登录访问时跳转原目标页或工作台。
- 目标：建立当前浏览器标签页会话，不泄露账号是否存在。

## 布局

- 独立全屏布局，不显示工作区侧栏和全局顶栏。
- 中央登录卡：品牌标识、产品名、说明、登录表单、通用错误提示。
- 原型的“快捷体验不同角色”只保留在显式开发/演示环境，生产构建不显示。

## 字段

| 字段 | 类型 | 规则 |
| --- | --- | --- |
| 工作邮箱 | email | 必填；trim、转小写；最多 254 字符 |
| 登录密码 | password | 必填；不回显、不记录；提交后可清空 |

原型中的“记住工作区会话”与 PRD 的 `sessionStorage` 规则冲突。生产页面删除该复选框；会话只在当前标签页有效。忘记密码若后端未提供流程，只显示“联系管理员”，不伪造重置接口。

## 功能与状态

- 提交期间禁用按钮并显示“正在登录”，防止重复请求。
- 统一显示“邮箱或密码错误”，不能区分未注册、密码错误、账号停用。
- 登录成功：保存短时 Bearer Token 到 `sessionStorage`，再调用 `/me` 与工作区列表。
- 有安全的原路径时返回原路径；原路径必须是同源白名单路由，否则进入工作台。
- Token 过期、成员关系失效、工作区无权限时清会话并显示可理解原因。
- 支持 Enter 提交；错误容器使用 `role="alert"`；提交完成后焦点移到错误或页面标题。

## 实现拆分

- 页面：`views/system/login/index.vue`（已有，按 v2.0 契约调整）。
- Model：邮箱规范化、回跳地址校验纯函数。
- Store：`auth` 仅保存当前会话身份与工作区；不要保存密码。
- API：`POST /api/v1/auth/login`、`GET /api/v1/me`、`GET /api/v1/workspaces`。

## 验收

- 无 Token、无效/过期 Token 均不能进入受保护页面。
- 刷新同一标签页可恢复会话，新标签页不自动共享 Token。
- 退出后浏览器后退不展示缓存敏感内容。
- 任意错误邮箱与错误密码响应文案和可观察时序一致。
- 恶意 `redirect` 参数不能形成开放重定向。
