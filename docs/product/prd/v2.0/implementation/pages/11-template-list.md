# P11 模板中心

## 页面定义

- 路由：`/templates`，对应原型 `#templates`。
- 目标：查看模板转换任务、模板草稿、不可变版本和发布状态。

## 布局

- 页头：标题、“从原件新建模板”（实际跳文档资产选择器）。
- Tab：全部模板、我的草稿、转换中/失败、已发布、已归档。
- 筛选：关键词、模板类型、状态、创建人、来源格式、更新时间。
- 主区建议用表格；模板名称、版本、类型、绑定数、质量状态和任务进度同时可比较。

## 列表字段

模板名称、类型 `fillable/reference`、当前版本、状态、绑定字段数、来源原件版本、转换/快照/质量状态、创建人、更新时间、操作。

转换任务独立显示 queued/converting/draft_ready/failed/retrying/cancelled，不能把任务状态写成模板发布状态。

## 操作

- 草稿：继续设计、取消草稿。
- ready：查看、发布、基于版本创建新草稿。
- published fillable：查看、创建新业务文档、基于版本创建草稿、归档。
- published reference：查看、继续设计、对比、审阅；没有业务文档创建入口。
- failed：查看失败阶段、按相同输入重试。
- 已转换原件再次发起时提供查看现有模板或复制为新模板。

## 实现拆分

- 延续 `views/template/list`，升级为服务端分页和任务状态区。
- `TemplateStatusBadge` 区分转换、草稿、版本和发布四套状态。
- 站内通知“转换完成”直接链接新草稿编辑器。

## 验收

- 只有 published + fillable + 有效绑定的模板显示“新建业务文档”。
- 发布新版本不会改变已创建业务文档。
- 历史版本不可编辑/删除，恢复会创建新草稿。
