# P21 文档对比列表

## 页面定义

- 路由：`/comparisons`，对应原型 `#compare`。
- 目标：检索权威对比任务，查看固定输入、处理状态、差异数量和调整结果。

## 布局

- 页头：标题、能力说明、“新建文档对比”。
- 筛选：关键词、模式、状态、输入类型、创建人、处理状态、时间范围。
- 表格：任务名、A/B 来源、模式、计算状态、处理状态、差异数、告警、创建时间、操作。

## 字段

- A/B 分别显示对象类型、名称、原件/模板版本或业务快照时间；不能只显示文件名。
- 模式：readonly/adjust；计算状态：queued/validating/parsing/comparing/completed/failed/cancelled。
- 处理状态：unreviewed/reviewed/adjusted/dismissed，与计算状态分离。
- 差异数量按文本、结构、格式、表格、图片、字段、页面设置提供摘要。

## 操作

- 运行中：查看进度；允许时取消。
- completed：查看结果、导出报告、复制任务链接。
- failed：查看双方失败阶段与告警，使用相同固定输入重试。
- adjusted：查看调整前结果与调整后权威结果；不提供业务文档“恢复版本”。

## 实现拆分

- `ComparisonTable`、`ComparisonSourceCell`、`DiffSummaryBadges`、`ComparisonFailureDrawer`。
- SSE 更新运行中任务；已完成页面不继续轮询。
- API 服务端分页并按对象权限过滤。

## 验收

- 任务列表能明确重建双方固定输入与算法版本。
- “仅对比”和“对比并调整”不混淆。
- 一侧权限失效后任务从普通列表隐藏或显示不可访问占位，不泄露名称。
