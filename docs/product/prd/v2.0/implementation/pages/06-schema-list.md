# P06 抽取方案列表

## 页面定义

- 路由：`/schemas`，对应原型 `#schemas`。
- 目标：检索、创建、查看和归档版本化抽取方案。

## 布局

- 页头：标题、说明、“新建抽取方案”。
- 筛选栏：关键词、状态、创建人、更新时间、排序。
- 推荐使用表格而非原型卡片作为主视图；字段数、版本和状态更适合比较。窄屏可转换为卡片。

## 列表字段

方案名称、当前版本、状态、字段数、敏感字段数、创建人、更新时间、被任务引用数、操作。

状态：draft、published、archived；历史发布版本不可变，被任务引用的版本不可物理删除。

## 操作

- 新建空白草稿、从已发布方案复制、打开详情/编辑草稿、查看版本历史、归档。
- 已发布方案“编辑”实际创建新草稿，文案必须避免用户误以为会修改历史版本。
- 无已发布方案时为新建抽取任务提供引导入口。

## 实现拆分

- 延续 `views/schema/list`，将原页面内 Builder 移至独立编辑路由后，列表容器保持轻量。
- `DmDataTable` 服务端分页；状态与筛选进入 URL query。
- API：列表、详情、创建草稿、创建版本、归档、复制。

## 验收

- Viewer/Reviewer 只能读，Owner/Admin/Editor 按能力写。
- 归档方案不再出现在正式抽取选择器，但历史任务仍可查看。
- 列表总数、引用数和权限范围一致。

## 子任务

- P06-T1：补草稿/版本/归档契约。
- P06-T2：实现列表筛选、版本入口和权限动作。
- P06-T3：补归档引用和角色测试。
