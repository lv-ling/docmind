# P22 新建文档对比

## 页面定义

- 路由：`/comparisons/new`，对应原型 `#compare-new`。
- 目标：完整支持“两份上传、上传+系统、两份系统”并明确仅对比或唯一调整目标。

## 布局

- 上方左右两个对称槽位：基线 A、比较 B；每个槽位可选“上传文件”或“从系统选择”。
- 中部：交换双方、输入摘要、状态/可编辑性检查。
- 下部：模式选择、调整目标（需要时）、确认创建。

## 文档槽位

系统选择支持原件版本、模板版本、业务文档当前内容；显示类型、名称、版本/快照时间、更新时间、状态和可编辑性。

上传支持 DOC/DOCX/PDF、最大 10MB，必须先完成安全验证并固化临时不可变版本。两槽位上传流程互相独立，取消时按保留策略清理。

## 模式规则

- 仅对比：双方始终只读，即使业务文档可编辑。
- 对比并调整：至少一侧是当前用户负责、状态 editing_internal 且可取得租约的业务文档。
- 仅一侧可编辑时自动选为目标；两侧均可编辑时必须选择唯一目标；均不可编辑时禁用并解释。
- 原件、模板、临时上传、外部编辑、审批中、已完成业务文档不可作为目标。
- A/B 方向在创建后固定；“交换双方”是创建前动作，创建后需新建任务。

## 创建

- 确认页显示双方来源、摘要、模式、目标、算法能力和 PDF/扫描件可靠度提示。
- 业务文档自动创建只读对比快照；请求固定输入摘要和算法版本。
- 创建带幂等键，返回 diff ID/job ID；跳任务进度或结果页。

## 实现拆分

- 复用 `DocumentPicker`，增加 slot scope 和 upload session。
- `ComparisonEligibilityPanel` 使用服务端返回的 reason code，不在前端猜权限。
- 交换只交换已选引用和 UI 标签，不复制上传文件二进制。

## 验收

- 三种来源组合全部可创建。
- 仅对比入口面对可编辑文档也无目标/保存能力。
- 两侧可编辑时未选目标无法提交。
- 一侧转换失败不产生部分权威结论。

## 子任务

- P22-T1：扩展临时上传和文档引用联合契约。
- P22-T2：实现双槽 DocumentPicker、交换和资格检查。
- P22-T3：补三组合、模式、唯一目标和幂等 E2E。
