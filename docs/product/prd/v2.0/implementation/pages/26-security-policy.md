# P26 数据安全策略

## 页面定义

- 路由：`/settings/security-policies`，对应原型 `#security`。
- 访问：Owner/Admin 管理；有需要的其他角色只读查看生效摘要。
- 目标：版本化管理国家、PII 类型、自定义 RE2/词典和受控 Validator。

## 布局

- 列表：名称、当前版本、状态、国家、PII 类型数、自定义规则数、创建人、更新时间。
- 筛选：关键词、国家、状态、创建人。
- 编辑 Drawer/独立页：基础信息、国家/内置类型、自定义规则、测试样例、发布摘要。

## 字段

- 名称、描述、国家范围（CN/US/JP/KR/DE/FR/GB/AU/NL）。
- 内置类型：电话、邮箱、身份证件、护照、银行账户、姓名、位置等。
- 自定义 RE2：名称、pattern、类型、敏感等级、掩码策略、正/反样例。
- 词典：名称、受限条目上传/编辑、大小统计；不在审计里记录内容。
- Validator：只能从服务端 allowlist 选择。

## 规则

- 草稿可编辑，发布版本不可变；任务固定引用版本。
- RE2 编译、复杂度、词典 10,000 项/总字符限制由服务端最终校验。
- 提供沙盒测试，只返回命中类型和掩码结果，不把测试明文写日志。
- 敏感识别不可用时不能发布或让抽取绕过安全检查。

## 验收

- 非管理员无法写；自定义代码/回溯正则无法提交。
- 历史任务结果不随策略新版本变化。
- 审计只记录版本、规则数量和动作，不记录 pattern/词典/测试明文。

## 子任务

- P26-T1：补草稿/发布/归档和测试接口。
- P26-T2：实现策略列表、规则编辑和样例测试。
- P26-T3：补 RE2、限制、权限和日志安全测试。
