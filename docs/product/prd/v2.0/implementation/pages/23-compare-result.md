# P23 对比结果与调整

## 页面定义

- 路由：`/comparisons/:id`，对应原型 `#compare-result`。
- 目标：查看可定位、可筛选、可审计的权威 Diff；仅在合法 adjust 模式编辑唯一业务目标。

## 布局

- 顶栏：A/B 来源、版本/快照时间、模式、算法版本、可靠度/告警、差异数；adjust 模式显示目标和保存。
- 工具栏：并排/统一/仅差异视图、差异筛选、上一个/下一个、同步滚动、缩放、折叠一侧、导出。
- 主区：A/B 双栏文档视图，按 diff anchor 定位；窄屏改为 Tab。
- 右侧可折叠差异列表/详情；底部或 Drawer 显示批注线程。

## 差异类型

文本插入/删除/替换、块结构、移动、字符/段落格式、表格结构/单元格、图片、页眉页脚、页面尺寸/方向/分节/分页、模板绑定、业务字段值。

每项显示类型、摘要、A/B before/after、位置、可靠度、是否可安全应用、处理状态、批注数。颜色之外必须有图标和“新增/删除/修改/移动”文字。

## 只读模式

- 无编辑器和保存按钮；可筛选、定位、批注、标记已审阅、导出报告。
- 无差异时显示“在当前算法和支持范围内未发现差异”，同时显示告警和算法版本。

## 调整模式

- 目标侧取得业务编辑租约；基线侧始终只读。
- 用户可在受控字段/原生修订会话中手改；安全映射项可“将 A 应用到 B”，按钮写清方向。
- 应用前展示实际 patch；AI 解释只作建议，不自动应用。
- 前端草稿 Diff 明确标“尚未保存”，超容量时降级为保存后计算。
- 保存检查租约/If-Match，更新同一业务文档，生成调整后快照并创建新权威 Diff；原任务保留。

## 批注与导出

- 批注锚定权威 diff ID/change ID，支持回复、解决、重开。
- 导出包含双方固定来源、摘要、算法、差异摘要/明细和告警，不包含无权查看的敏感明文。

## 实现拆分

- `ComparisonHeader`、`DiffToolbar`、`DiffDocumentPane`、`DiffChangeList`、`DiffCommentDrawer`。
- 长差异列表虚拟化；双栏滚动按节点锚点同步，不按简单 scrollTop 百分比。
- adjust 编辑职责复用业务文档租约/保存 composable，不复制写入逻辑。

## 验收

- 点击差异同时定位双方对应位置，无法定位时明确告警。
- 仅对比永远不能通过 UI/API 保存。
- 保存冲突不覆盖；成功后展示调整后权威结果。
- 原件和模板在任意组合下不可被修改。
