# P20 外部填写

## 页面定义

- 路由：公开高熵 token 路由，例如 `/external/fill/:token`，对应原型 `#external-fill`。
- 访问：无需系统账号；有效 token 持有人，按配置再校验访问码。
- 目标：只查看必要上下文并填写被授权字段，暂存或一次提交。

## 布局

- 独立品牌页，不加载内部侧栏、用户信息、全局搜索或内部 API 数据。
- 顶部：文档显示名、发起组织、有效期、隐私说明、轮次状态。
- 主区：只读文档预览 + 授权字段覆盖层/字段面板。
- 底部固定操作：暂存（若允许）、提交；移动端字段面板改为单栏。

## 访问与字段

- 首屏先验证 token 状态；启用访问码时通过独立表单验证后才返回文档上下文。
- 只返回允许查看的上下文和允许填写字段；内部批注、审批链、模板信息、对象 ID 不下发。
- 字段类型/校验与内部填写一致；敏感既有值按外部授权决定是否显示。
- 明确显示链接有效期、尝试剩余次数和“这不是电子签名/实名认证”。

## 暂存与提交

- 暂存带外部 session、content revision 和幂等键；刷新可恢复已暂存字段。
- 提交前显示字段摘要并二次确认；提交成功立即关闭本轮编辑并生成审计快照/第一审批待办。
- 结果页可刷新但不得重复提交；不自动跳内部登录页。
- 审批驳回后原 token 只有在被明确 reopened 时才能再次填写，否则使用新 token。

## 安全

- token 数据库存哈希；访问码慢哈希；按 IP/token/工作区限流并记录最小审计。
- 响应 `Cache-Control: no-store`、严格 CSP、禁止 referrer 泄露 token。
- 页面错误不区分“文档不存在”和“无权访问”；过期/撤销可以给通用终态说明。
- 外部页面不能加载内部用户头像、通知或其他跨租户资源。

## 验收

- 只能修改授权字段；篡改字段 key、文档 ID、revision 会被拒绝。
- 重复提交只产生一次快照和一个审批待办。
- submitted/expired/revoked/completed 状态均不可继续写。
- 外部会话和内部编辑待办绝不同时活动。

## 子任务

- P20-T1：建立公开外部会话与访问码/限流契约。
- P20-T2：复用受控字段组件并隔离内部应用壳。
- P20-T3：实现暂存、提交结果、CSP/no-store。
- P20-T4：补 token 枚举、重放、撤销和模式互斥安全测试。
