# P03 工作台

## 页面定义

- 路由：`/workbench`，对应原型 `#workbench`。
- 目标：让用户在一个页面看到当前要处理的事项、时间范围内的指标和高频入口。

## 布局

1. 欢迎区：用户、角色、当前工作区、待处理总数；右侧“上传原件”“新建业务文档”。
2. 指标卡：处理文档数、抽取成功率、待复核/待审批、已发布模板、流转中/完成文档、平均时长。
3. 左侧趋势图：抽取、业务流转折线；右侧快捷入口与紧急待办。
4. 近期处理事项表：抽取、业务文档、传阅和失败任务的统一活动流。

## 筛选与指标

- 全页时间范围：最近 7 天、30 天、自定义；所有卡片和图表显示同一范围。
- 字段准确率只计算已批准数据；未复核结果只显示置信度。
- 时间一天内显示相对时间，超过一天显示完整日期时间并在 tooltip 中显示时区。
- 指标响应返回 numerator、denominator、time_range，前端不自行猜测口径。

## 待办卡字段

文档名称、任务类型、当前状态、发起人、更新时间、截止时间、整体置信度（仅抽取）、阻断原因、主操作。

主操作按状态显示“去复核”“去填写”“去审批”“查看传阅”“处理失败”；没有处理权限时只能查看。

## 快捷入口

- 上传原件、新建抽取、进入复核队列、新建业务文档、新建对比、发起智能审阅。
- capability 不足时隐藏或禁用并说明原因。
- 没有已发布 `fillable` 模板时，“新建业务文档”跳转模板中心引导，不进入空向导。

## 实现拆分

- 沿用 `views/workbench/overview` 的区域组件和 model。
- 新增 `WorkbenchMetricGrid`、`DocumentFlowChart`、`UnifiedAttentionTable`。
- 图表封装 ECharts option；表格使用 `DmDataTable`。
- API 返回聚合视图，避免前端请求所有明细再统计。

## 状态

- 指标、趋势、待办分别显示 skeleton；局部失败不阻断其他区块。
- 无待办显示快捷操作；无统计权限显示权限说明而不是 0。
- 失败任务必须显示失败阶段和可重试性。

## 验收

- 页面各指标与 PRD 指标口径一致，切换时间范围后同步刷新。
- 点击主操作到达具体对象且服务端再次校验权限。
- 小屏图表和表格不导致横向页面溢出。
- 局部 API 失败可单独重试。

## 子任务

- P03-T1：定义工作台聚合 API 与指标口径测试。
- P03-T2：实现指标、趋势、快捷入口和统一待办。
- P03-T3：补时间范围、权限、空态和局部错误测试。
