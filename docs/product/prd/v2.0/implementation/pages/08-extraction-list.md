# P08 抽取任务与复核队列

## 页面定义

- 路由：`/extractions` 与 `/extractions/review-queue`，对应原型两个 hash。
- 目标：查看所有抽取任务或只查看当前可处理的复核任务。

## 布局

- 共享页面框架，队列路由预设 `status=review_required,reviewing` 和 `assignee=me`。
- 页头、“创建抽取任务”、筛选栏、任务表、分页。
- 运行中任务在行内显示阶段进度；失败行可展开诊断。

## 列表字段

任务 ID、输入名称/类型、输入版本或快照时间、抽取方案版本、安全策略版本、状态/阶段、整体置信度、创建人、复核人、创建/更新时间、操作。

未进入复核前不显示伪造置信度；批准后可显示最终状态但准确率单独按指标计算。

## 筛选

关键词、输入类型、状态、方案、创建人/复核人、时间范围、是否可重试；默认按更新时间倒序。

## 状态与操作

- queued/parsing/extracting/validating：查看进度、可取消时取消。
- review_required/reviewing：开始/继续复核。
- approved：查看批准结果、导出 JSON。
- rejected：查看原因、基于相同输入新建任务。
- failed：显示失败阶段、可重试性、尝试次数；可重试时使用相同输入快照。

## 实现拆分

- 一个领域页面通过 route preset 区分任务中心/复核队列，不复制页面。
- SSE 更新当前页任务；断线后降级轮询，终态停止订阅。
- `ExtractionStatus` 使用可辨识联合，禁止多个矛盾布尔状态。

## 验收

- 刷新后任务阶段恢复；重复消息不生成重复行或结果。
- 无对象权限的任务不能通过 ID 打开。
- 技术失败和人工驳回状态、文案、操作完全分离。
- 复核队列只展示用户可查看/处理的项目。

## 子任务

- P08-T1：补列表筛选/分页和事件契约。
- P08-T2：实现共享列表、队列 preset 与行进度。
- P08-T3：补 SSE 恢复、失败重试和权限测试。
