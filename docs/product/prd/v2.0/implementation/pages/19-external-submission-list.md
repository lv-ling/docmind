# P19 外部提交管理

## 页面定义

- 路由：`/external-submissions`，对应原型 `#external-mgmt`。
- 目标：管理外部编辑模式业务文档的链接、填写轮次、访问状态和内部审批结果。

## 布局

- 指标：有效链接、已提交待审批、已过期、已撤销。
- 筛选：文档、链接状态、提交状态、发起人、到期时间。
- 表格：业务文档、轮次、有效期、访问码状态、尝试次数、允许暂存、字段范围、状态、操作。
- 链接详情 Drawer：访问/暂存/提交事件、审批状态和审计摘要。

## 安全展示

- 不在列表显示完整外链 token 或访问码；只显示 token 尾号/创建时间与“已设置访问码”。
- “复制链接”向服务端请求当前有效公开 URL；不得通过业务文档 ID 自行拼接。
- 访问码不可读取原值，只能重置。

## 操作

- 复制链接、延长有效期、重置访问码、撤销、查看提交、取消流程。
- submitted_closed/awaiting_approval 时不能重新开放填写。
- 驳回后按审批决策显示 reopened 或 replaced；同一时刻最多一个有效可编辑链接。
- 删除业务文档前必须撤销链接并使所有外部会话失效。

## 实现拆分

- `ExternalSubmissionTable`、`ExternalLinkStatus`、`ExternalAccessTimeline`。
- 复制使用 Clipboard API，失败时显示可选中的安全 URL Dialog。
- 访问事件服务端分页且不展示 IP 以外的多余身份猜测。

## 验收

- 过期、撤销、达到上限和提交关闭链接均不能继续编辑。
- 撤销后现有外部会话下一次请求立即失效。
- 日志和页面源代码不包含访问码、token 哈希或对象地址。

## 子任务

- P19-T1：实现外链轮次、管理动作和审计契约。
- P19-T2：实现列表、详情 Drawer 和安全复制。
- P19-T3：补撤销、过期、替换和删除联动 E2E。
