# PRD v0.1.1

状态：Draft  
目标：在不破坏 v0.1 安全抽取闭环的前提下，将模板从“流式受控 HTML 微调”升级为“高保真分页预览 + Word 原生富文本编辑 + 系统字段绑定”。  
范围：高保真模板转换、DOCX 网页编辑、内容控件字段绑定、模板版本固化和旧模板兼容。

## 版本定位

v0.1.1 是进入 v0.2 前的质量补丁阶段。它不增加模板实例、批注、纠错或双文档 Diff，而是先替换 v0.1 中还原度不足的模板编辑底座，避免后续能力依赖不可分页的流式 HTML。

## 包含

- DOC/DOCX 原件保持不可变，并生成逐页 PDF 对照预览。
- DOC 转为隔离的工作 DOCX，DOCX 以原生文件作为模板编辑载体。
- 右侧嵌入自托管文档编辑器，提供选择区级别的字体、字号、颜色、粗体、段落、表格、分页和页眉页脚编辑。
- 使用 Word Content Control 保存字段绑定，系统字段清单独立持久化并在保存时校验。
- 模板版本同时固化可编辑 DOCX、PDF 快照、字段清单、校验结果和派生文档模型。
- PDF 原件继续使用固定页面预览；模板字段使用页面坐标覆盖层，不把 PDF 强制转为流式 Word。
- 旧受控 HTML 模板保持只读和可回滚，支持从其原件按需创建原生编辑版本。

## 不包含

- 任意复杂 Word 与 Microsoft Word 像素级完全一致。
- VBA、宏执行、嵌入式 OLE 程序和外部活动内容。
- 任意 PDF 正文重排式编辑。
- 多人协同、模板实例、批注、智能纠错和双文档 Diff；这些仍由 v0.2/v1.0 承接。
