# PRD v0.1

状态：Draft  
目标：验证 Word 到可审核 HTML 模板和安全 JSON 的最小可用闭环  
范围：单工作区、单份 Word/PDF、单次抽取、模板人工校验

## 本版本回答的问题

用户能否上传一份常见 Word，自定义带默认值的 JSON 字段，在不向模型暴露敏感数据的条件下获得可追溯 JSON，并把 Word 转成可人工校验的 HTML 模板？

## 包含

- DOCX/PDF 上传（单文件 <= 10MB）、原件不可编辑预览和版本保存；支持图片、表格、页眉页脚、目录
- 表单定义字段：key、描述、类型、必填、未找到默认值、敏感级别
- Schema 保存为可复用模板，抽取时选择 Schema 模板
- 敏感规则模板：国内外手机号、邮箱、身份证和自定义规则
- 应用层脱敏、异步解析、结构化字段抽取和受控回填
- 字段值、默认值来源、置信度、页码/文本证据
- DOCX 到受控 HTML 模板的转换、保存和左右人工校验
- 任务状态、失败重试和基础审计

## 不包含

模板实例填写、编辑锁、实时同步、双文档 Diff、批注、模板导出、电子印章和复杂组织权限。

详细需求见 [PRD.md](PRD.md)。
