# 背景与范围

## 背景

企业合同、报价单、制度、项目材料等信息分散在 Word 文档中。人工阅读、复制、改版、填写和比对耗时，且结果无法复用；单纯 OCR 只能得到文字，不能稳定保留段落、表格、图片、层级和上下文。

DocMind 将处理过程拆成可验证的链路：原始 Word 版本化保存 -> 应用层解析和敏感信息脱敏 -> AI 按用户 Schema 抽取 -> 应用层回填敏感值并校验 -> 模板转换与人工校验 -> 模板实例填写、锁定协作与提交 -> 两类文档比对。每个 AI 结果都要能回指原文证据。

## 产品愿景

让 Word 文档成为可提取、可复现、可填写、可比较、可审计的数据资产，而不是一次性附件。

## 目标产品范围

- 导入、预览、版本管理和权限控制；支持 DOCX/PDF，单文件不超过 10MB，并支持图片、表格、页眉页脚和目录。
- 用户通过表单定义 JSON 字段：`key`、字段描述、类型、必填性、未找到时的默认值和敏感级别；默认值可以为空字符串，没有默认值时返回 `null`；字段定义可以保存为 Schema 模板，后续选择模板快速复用。
- 应用层使用确定性敏感识别组件检测并替换身份证、手机号、邮箱及自定义规则；模型只看到稳定占位符，应用层只回填来自原文的值。
- DOCX 转成受控 HTML 文档模型，保存为“模板”；用户可在左侧原 Word/PDF 预览、右侧模板之间人工检查格式与文字差异，原件永远不可编辑。
- 用户基于模板创建“模板实例”，填写占位字段并保存、提交；同一实例同一时间只允许一人进入编辑锁，其他人实时看到已保存内容和锁定状态。
- 支持上传 Word 对比和已审核 HTML 文档（模板/模板实例）对比；后者优先使用结构化 HTML，结果更准确。

## 非目标

不承诺法律意见、自动签署合同、无审核的全自动盖章、通用桌面排版替代，以及对任意复杂 Word 的 100% 像素级还原。首期协作采用“单人编辑锁 + 其他人实时只读同步”，不做无锁的多人同时编辑和自动合并。

## 成功指标

MVP 以可测量结果为准：常见字段抽取准确率 >= 90%；敏感值明文发送到模型的比例为 0；10MB 以内 DOCX/PDF 解析任务 95 分位 <= 2 分钟；所有 AI 字段结果具备证据覆盖率 100%；模板实例的编辑锁冲突不会产生静默覆盖。

## 术语

原件（Source Document）是不可编辑的导入 Word 及其预览；模板（Template）是从原件转换并经人工调整的受控 HTML 结构，不携带具体业务填写值；模板实例（Document Instance）是由模板创建、携带业务数据且可提交的文档；抽取 Schema 是用户定义的 JSON 返回约束；证据（Evidence）是结果对应的原文范围。
