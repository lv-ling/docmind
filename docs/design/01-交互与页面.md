# 交互与页面

技术/交互基线：T0.1  
适用产品：PRD v0.1-v1.0，按版本逐步启用
状态：Draft

## 信息架构

工作台、原件中心、抽取任务、模板中心、模板实例、对比中心、设置与审计。页面统一显示工作区、对象类型、当前版本、任务状态和权限；原件、模板、模板实例必须用不同标识，防止用户把模板误认为已填写文档。

## 抽取工作台

左侧原件只读预览，中间字段树/JSON，右侧证据和复核操作。Schema 编辑器支持 `key`、描述、类型、必填、默认值、敏感级别；保存前做实时校验。字段明确显示“抽取值、默认值或人工值”，敏感值在无查看权限时掩码显示。点击字段联动原件高亮。

## Web 编辑器

模板编辑器只接受受控文档节点，不直接执行任意 HTML/脚本。进入“原件-模板校验”时左侧固定为只读 PDF/页图预览，右侧模板可切换预览/编辑；这是人工转换质量检查，不显示自动增删差异。顶部显示模板版本、原件版本、保存状态和转换告警；模板保存创建新版本，不能回写原件。

默认左右分栏可拖拽调整宽度，支持折叠任一栏并保存用户偏好。两栏支持独立滚动与“同步滚动”开关、缩放、按页码/节点跳转；点击转换告警会同时定位左侧原件和右侧受控节点。页眉页脚、表格、图片和分页提示以受控节点编辑；无法编辑或无法保真的内容显示明确的降级说明。

## 模板实例与协作

用户从已发布模板创建模板实例，再填写字段和文档内容。点击编辑时请求编辑锁：成功者可编辑，其他用户页面显示“由某用户编辑中”，但不可输入。编辑者的变更通过节流后的内容操作事件实时广播，其他用户以只读方式同步看到 A 用户正在编辑的内容；服务端定期生成内容快照，避免仅依赖浏览器事件。编辑者定期续约；关闭、主动退出或超时后锁释放。保存使用版本号校验，网络分区后的陈旧写入必须提示刷新、比较或另存，不能覆盖新内容。

字段控件显示必填、格式、枚举、敏感掩码和权限状态。批注以节点范围、原文引号和上下文锚定；正文变化后无法可靠定位时显示“需重新定位”。纠错建议显示类别、严重程度、原因和可选替换，用户只能接受或忽略，系统不自动改写文本。以上实例、批注和纠错能力自 v0.2 启用。

## 对比与审阅

对比中心自 v1.0 启用，支持三种来源组合：两份上传文件、两个系统已保存版本、上传文件与系统已保存版本。上传文件在服务端转为临时只读原件版本后再比较。

对比中心有两类结果：

1. **后端权威 Diff**：上传 DOC/DOCX/PDF 时异步解析、转换和比较；模板/实例版本直接比较受控 HTML 节点、文本、格式和数据字段。结果可审计、可重放，但上传比较受转换准确度影响。
2. **前端实时草稿 Diff**：用户编辑模板/实例时，浏览器在 Web Worker 中与已加载基线做增量对比。结果标为“草稿差异，尚未保存”，不上传未保存内容，也不作为审计记录；保存后以权威 Diff 替换。

两类结果都支持并排与统一视图、仅差异视图、差异导航、同步/独立滚动、缩放、折叠面板和按页/节点定位。左侧删除/旧内容使用红色加“已删除”文字，右侧新增/新内容使用绿色加“已新增”文字；颜色不是唯一状态信号。字段变化按 JSON Path 聚合，格式变化显示前后属性；AI 风险解释必须标注“AI 建议”并附证据，用户可接受、忽略或添加批注。

## 无障碍与安全

键盘可完成上传、字段跳转、接受/忽略和批注；颜色之外提供图标/文字状态。预览内容经过 HTML 白名单清洗，下载和外链均走鉴权；错误信息不暴露对象存储路径或模型内部提示词。
