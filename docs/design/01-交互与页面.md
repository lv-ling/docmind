# 交互与页面

技术/交互基线：T0.1  
适用产品：PRD v0.1，编辑能力在 PRD v0.2 扩展  
状态：Draft

## 信息架构

工作台、原件中心、抽取任务、模板中心、模板实例、对比中心、设置与审计。页面统一显示工作区、对象类型、当前版本、任务状态和权限；原件、模板、模板实例必须用不同标识，防止用户把模板误认为已填写文档。

## 抽取工作台

左侧原件只读预览，中间字段树/JSON，右侧证据和复核操作。Schema 编辑器支持 `key`、描述、类型、必填、默认值、敏感级别；保存前做实时校验。字段明确显示“抽取值、默认值或人工值”，敏感值在无查看权限时掩码显示。点击字段联动原件高亮。

## Web 编辑器

模板编辑器只接受受控文档节点，不直接执行任意 HTML/脚本。进入“原件-模板校验”时左侧固定为只读原件预览，右侧模板可切换预览/编辑；这是人工转换质量检查，不显示自动增删差异。顶部显示模板版本与保存状态；模板保存创建新版本，不能回写原件。

## 模板实例与协作

用户从已发布模板创建模板实例，再填写字段和文档内容。点击编辑时请求编辑锁：成功者可编辑，其他用户页面显示“由某用户编辑中”，但不可输入。编辑者的变更通过节流后的内容操作事件实时广播，其他用户以只读方式同步看到 A 用户正在编辑的内容；服务端定期生成内容快照，避免仅依赖浏览器事件。编辑者定期续约；关闭、主动退出或超时后锁释放。保存使用版本号校验，网络分区后的陈旧写入必须提示刷新/另存，不能覆盖新内容。

## 对比与审阅

对比中心有两种模式：

1. **上传 Word 对比**：用户上传 A、B 两份 DOCX；系统分别异步解析并生成临时 HTML 后再比较。左侧红色突出删除/旧内容，右侧绿色突出新增/新内容；页面提示转换耗时和结果受转换准确度影响。
2. **已审核 HTML 对比**：用户选择模板或模板实例版本进行比较。直接比较受控 HTML 节点、文本和数据字段，左侧红色、右侧绿色展示，结果更快、更准确。

两种模式都支持并排与统一视图。字段变化按 JSON Path 聚合，AI 风险解释必须标注“AI 建议”并附证据，用户可接受、忽略或添加批注。

## 无障碍与安全

键盘可完成上传、字段跳转、接受/忽略和批注；颜色之外提供图标/文字状态。预览内容经过 HTML 白名单清洗，下载和外链均走鉴权；错误信息不暴露对象存储路径或模型内部提示词。
