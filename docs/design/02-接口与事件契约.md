# 接口与事件契约

契约版本：API v1，技术基线 T0.1  
适用产品：PRD v0.1  
状态：Draft

## API 约定

HTTP API 以 `/api/v1` 开头，统一返回 `request_id`。资源使用复数名词；创建异步任务返回 `202 + job_id`；分页使用 `cursor`。写操作支持 `Idempotency-Key`，更新使用 `If-Match` 防止覆盖。

## 事件

事件使用 CloudEvents 形态，关键事件包括 `source.version.created`、`extraction.completed`、`template.generated`、`template.version.published`、`instance.lock.acquired`、`instance.saved`、`instance.submitted`、`instance.lock.released`、`comment.thread.created`、`proofreading.completed`、`diff.completed`。事件包含 `event_id`、`workspace_id`、`aggregate_id`、`occurred_at`、`schema_version` 和产生写操作的 `idempotency_key`；消费者按 `event_id` 幂等。敏感字段事件只传递掩码值或受控字段 ID，不传明文。浏览器草稿 Diff 不发布领域事件。

领域事件与内部任务命令分开：RabbitMQ `docmind.async-job.v1` 命令只包含 `schema_version/message_id/job_id/workspace_id/job_type/aggregate_type/aggregate_id/attempt/request_id/created_at`。`message_id` 在同一任务的重投中保持为任务 ID，`attempt` 单调递增；消费者必须将所有字段与数据库任务交叉校验。消息使用持久投递、手动确认和独立 DLQ，任何异常消息、未知处理器或终态失败都不能无限 requeue。

## 错误模型

```json
{"code":"SCHEMA_INVALID","message":"字段定义无效","details":{},"request_id":"..."}
```

错误码分为鉴权、参数、资源、冲突、任务、依赖和限流；面向用户的 message 不包含堆栈、密钥、原文或内部 URL。
