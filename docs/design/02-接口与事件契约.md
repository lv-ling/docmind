# 接口与事件契约

契约版本：API v1，技术基线 T0.1  
适用产品：PRD v0.1  
状态：Draft

## API 约定

HTTP API 以 `/api/v1` 开头，统一返回 `request_id`。资源使用复数名词；创建异步任务返回 `202 + job_id`；分页使用 `cursor`。写操作支持 `Idempotency-Key`，更新使用 `If-Match` 防止覆盖。

## 核心接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/workspaces/{id}/sources` | 创建 DOCX/PDF 原件上传会话（<=10MB） |
| POST | `/sources/{id}/versions/complete` | 完成上传并创建原件版本 |
| POST | `/source-versions/{id}/extractions` | 按字段 Schema 创建脱敏抽取任务 |
| GET | `/workspaces/{id}/schema-templates` | 查询可复用 Schema 模板 |
| POST | `/workspaces/{id}/schema-templates` | 保存表单字段为 Schema 模板 |
| GET | `/workspaces/{id}/sensitive-rule-templates` | 查询敏感规则模板 |
| POST | `/workspaces/{id}/sensitive-rule-templates` | 保存自定义敏感规则模板 |
| GET | `/extractions/{id}` | 查询状态、结果和证据 |
| POST | `/extractions/{id}/approve` | 审批结果 |
| POST | `/source-versions/{id}/templates` | 创建 Word 转 HTML 模板任务 |
| POST | `/templates/{id}/versions` | 保存模板微调，创建模板新版本 |
| POST | `/template-versions/{id}/instances` | 从模板创建可填写实例 |
| POST | `/instances/{id}/edit-lock` | 获取或续约实例编辑锁 |
| DELETE | `/instances/{id}/edit-lock` | 主动释放实例编辑锁 |
| PATCH | `/instances/{id}` | 保存实例，必须携带 `If-Match` revision |
| POST | `/diffs/word` | 上传/选择两份 Word 创建异步对比 |
| POST | `/diffs/html` | 选择模板或实例版本创建结构化 HTML 对比 |
| GET | `/workspaces/{id}/llm/providers` | 查询已配置的模型供应商和模型名 |
| PUT | `/workspaces/{id}/llm/providers/{provider}` | 保存或更新加密的 API Key、模型名和参数 |

## 事件

事件使用 CloudEvents 形态，关键事件包括 `source.version.created`、`extraction.completed`、`template.generated`、`template.version.published`、`instance.lock.acquired`、`instance.saved`、`instance.lock.released`、`diff.completed`。事件包含 `event_id`、`workspace_id`、`aggregate_id`、`occurred_at`、`schema_version`；消费者按 `event_id` 幂等。敏感字段事件只传递掩码值或受控字段 ID，不传明文。

## 错误模型

```json
{"code":"SCHEMA_INVALID","message":"字段定义无效","details":{},"request_id":"..."}
```

错误码分为鉴权、参数、资源、冲突、任务、依赖和限流；面向用户的 message 不包含堆栈、密钥、原文或内部 URL。
