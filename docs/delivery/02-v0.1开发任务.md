状态：Implementing  
目标：按依赖顺序完成 `packages -> Java API -> Python AI -> Web -> 联调验收`。  
更新规则：只有某一级任务下的所有子任务完成并通过验证，才能勾选该一级任务。

- `[ ]` 未完成

- 阻塞任务在标题后标记 `阻塞：原因`
- 每次完成任务必须在“完成记录”中写明日期、验证命令和结果

- [ ] P0 Packages：契约、编辑器模型和 UI 基础包
- [ ] J0 Java API：业务后端和基础设施接入
- [ ] A0 Python AI：解析、脱敏、抽取与 Mock 模型

- [ ] I0 联调验收：端到端链路、测试和文档

## 依赖顺序

```text
P0 Packages
  -> J0 Java API
  -> A0 Python AI
  -> W0 Web
  -> I0 联调验收
```

Java API 完成最小上传/任务接口后，Python AI 可以与 Java 后续任务并行；Web 在 OpenAPI 和首批 API 稳定后开始。总体勾选仍按每一端全部任务完成为准。
