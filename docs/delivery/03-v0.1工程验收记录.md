## 联调中修复的问题

- 根路由循环重定向和会话失效后导航。
- 受保护原件/预览不能直接作为 iframe URL，改为鉴权获取 Blob URL 并及时释放。
- 原件预览缺少异步任务及历史回填；增加任务类型、迁移与 PDF 实际页数校验。
- Java 全局忽略空值导致 Python 必填可空字段、模板排队态和抽取结果契约缺字段；关键响应显式保留 JSON `null`。
- 二次 PII 扫描误扫 JSON 节点 UUID；限制为业务数据、候选值和证据文本。
- Vue 响应式 Proxy 无法被 `structuredClone` 保存；在 API 边界改为 JSON 值克隆并增加回归测试。
- PostgreSQL 正则方言约束只接受 `RE2`，与公开契约 `re2` 不一致；V13 迁移统一为小写契约值。
