# 领域模型与数据库

技术基线：T0.1  
适用产品：PRD v0.1  
状态：Draft

## 核心实体

`workspace` 工作区；`member` 成员与角色；`source_document` 原件逻辑对象；`source_version` 不可变 DOCX/PDF 版本；`source_preview` 原件只读预览；`parsed_content` 带位置的中间文档模型；`extraction_schema` 用户字段定义；`schema_template` 可复用 Schema 模板；`extraction_run` 抽取任务；`extraction_field` 字段值、证据、默认值来源和复核状态；`sensitive_rule_template` 可复用敏感规则模板；`sensitive_token` 加密令牌映射；`llm_provider_config` 加密的供应商/模型配置；`template` 逻辑模板；`template_version` 受控 HTML 模板版本；`document_instance` 模板实例；`instance_version` 实例内容和数据快照；`edit_lock` 编辑租约；`diff_run` 对比任务；`audit_event` 审计事件。

## 关系与约束

- 所有业务表带 `workspace_id`、`created_at`、`updated_at`；软删除使用 `deleted_at`。
- `source_version` 通过 `(source_document_id, version_no)` 唯一；文件对象键和 SHA-256 唯一；仅允许 DOCX/PDF 且 `size_bytes <= 10MB`。原件永不被模板编辑覆盖。
- `extraction_schema_field` 以 `(schema_version_id, key)` 唯一，保存 `description/type/required/default_value/sensitivity`；`schema_template` 保存字段定义快照；`extraction_field` 保存 `value_json/value_source/evidence_json/confidence/review_status`。
- `sensitive_rule_template` 保存 Presidio Recognizer、正则、词典或校验器配置；`sensitive_token` 仅保存加密后的原始值、类型、令牌和任务作用域；令牌不可跨工作区、任务或版本复用。
- `llm_provider_config` 的 API Key 使用 Secret/KMS 加密，前端只能看到供应商和模型名，不能读取密钥明文。
- `template_version` 关联唯一的来源 `source_version_id` 与 `parsed_content_id`；`document_instance` 关联固定 `template_version_id`，不得因模板后续编辑而改变。
- `instance_version` 带递增 `revision`；保存时需携带 revision。`edit_lock` 以 `(instance_id)` 唯一，保存锁持有人、租约过期时间和最后心跳。

## 状态机

```text
source_version: uploading -> uploaded -> processing -> ready | failed
extraction_run: queued -> running -> review_required -> approved
                         |          |                 \-> failed -> retrying
template_version: generated -> checking -> published -> superseded
document_instance: draft -> editing -> saved -> submitted -> archived
diff_run: queued -> parsing -> comparing -> completed | failed
```

状态转换由服务端校验；客户端不能直接写状态。任务重试使用指数退避和最大次数，人工审批和实例提交是显式命令。编辑锁不等同于实例状态：锁释放后实例仍可能处于 `editing` 或 `saved`。

## 数据保留

原始文件、版本和审计记录默认保留 365 天，工作区可配置；删除采用回收站 + 延迟清理。模型输入输出按敏感等级脱敏后保留最小必要周期，禁止使用租户数据训练，除非有明确授权。
